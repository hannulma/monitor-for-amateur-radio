## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, preferably use the feedback function in the app by selecting **Program -> Feedback and bug reports**. 

For general bug reports or non-security feedback, you may open an issue on the [GitHub Issues page](https://github.com).
